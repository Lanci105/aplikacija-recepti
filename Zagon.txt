Zagon aplikacije Recepti (macOS)

Predpogoji
- Nameščen PostgreSQL 16 (npr. prek Homebrew).
- JDK 21 ali novejši.
- Node.js in npm.
- Projekt je kloniran iz GitHub repozitorija.

1. Zaženi PostgreSQL (prvi terminal)

brew services start postgresql@16

Bazo ustvari samo prvič, če še ne obstaja:

createdb recepti

Preveri povezavo:

psql -d recepti -c "SELECT current_database();"

2. Zaženi backend (drugi terminal)

V terminalu se najprej premakni v mapo projekta, nato zaženi:

cd backend
export DB_URL="jdbc:postgresql://localhost:5432/recepti"
export DB_USERNAME="$(whoami)"
export DB_PASSWORD=""
./mvnw spring-boot:run

Če PostgreSQL uporablja drugo uporabniško ime ali geslo, ustrezno spremeni DB_USERNAME in DB_PASSWORD. Pusti terminal odprt. Backend teče na http://localhost:8080.

3. Zaženi frontend (tretji terminal)

V novem terminalu se premakni v mapo projekta, nato zaženi:

cd frontend
npm ci
npm run dev

V brskalniku odpri naslov, ki ga izpiše Vite, običajno http://localhost:5173.

Prijava, profil in osebne funkcije
- Ustvari račun prek gumba Prijava/Registracija ali se prijavi s svojim računom.
- Vsak uporabnik naj uporablja svoje geslo. Gesel ne zapisuj v to datoteko ali v Git.
- Za urejanje profila, oddajo komentarja ali ocene ter brisanje lastnega komentarja se prijavi.
- Recepti se lahko dodajajo, urejajo in brišejo kot doslej.

Dodatno
- Swagger API dokumentacija: http://localhost:8080/swagger-ui/index.html
- Izpis receptov iz baze: psql -d recepti -c "SELECT * FROM recept;"
- Ustavitev strežnikov: v vsakem terminalu pritisni Ctrl+C.
- Ustavitev PostgreSQL po koncu dela: brew services stop postgresql@16
